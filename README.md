# Zulaikha & Iqbal

Static Next.js story, deployed with GitHub Actions to GitHub Pages.

```
npm install
npm run dev
```

Local URL: [http://localhost:3000/Zulaikha-Iqbal/](http://localhost:3000/Zulaikha-Iqbal/)

Live (after Pages is enabled): [https://letterfromme.github.io/Zulaikha-Iqbal/](https://letterfromme.github.io/Zulaikha-Iqbal/)

Copy `.env.example` to `.env.local` for Cloudinary credentials. Do not commit `.env.local`. After the first workflow run, set **Settings → Pages → Source** to GitHub Actions.
